CLOUD SERVICE MODELS

Three Ways to Use the Cloud

Cloud services can be provided at different levels of infrastructure and application management.

🖥️

IaaS

Infrastructure as a Service

Provides virtual machines, storage, networking and other infrastructure resources.

Example: AWS EC2
⚙️

PaaS

Platform as a Service

Developers deploy applications while the platform manages much of the underlying infrastructure.

This Demo: Render
🌐

SaaS

Software as a Service

Complete software applications are delivered through the internet without managing the underlying infrastructure.

Example: Google Workspace
